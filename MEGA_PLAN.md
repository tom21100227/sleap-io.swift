# MEGA_PLAN.md — Roadmap to GUI-ready parity

**Date:** 2026-06-10
**Derived from:** [`GAP_ANALYSIS.md`](GAP_ANALYSIS.md) (328-gap audit vs Python
`sleap-io` + `sleap-io.js`, weighted by `sleap.swift` GUI needs).
**North star:** unblock the native SwiftUI annotation GUI (`sleap.swift`) on macOS +
iPadOS, then a `sleap.swift` training/inference backend.

## How to read this

- **8 milestones** (`M1`…`M8`) ordered by GUI-unblock priority.
- **19 epics** (GitHub issues labeled `epic`), each a tracking issue with native
  sub-issues.
- Each **sub-issue** is written test-first: it names the upstream reference
  (`sleap_io.X` / `sleap-io.js Y`), the Swift target, acceptance criteria, and the
  TDD test cases to add. Every sub-issue must land with **its own new tests green**;
  the **full suite runs at the end** of a batch (per the agreed verification bar).

## Working conventions

- **TDD:** write failing tests first (red), implement to green, then refactor.
- **Git:** one feature branch + one PR per sub-issue, branch off `main`, PR linked to
  the sub-issue (`Closes #N`). Matches the existing PR flow (#3).
- **Branch naming:** `feat/<epic-id>-<slug>` e.g. `feat/e2-instance-numpy`.
- **No regressions:** additive APIs preferred; schema-changing work (provenance,
  SLP version, codecs) gets dedicated regression fixtures from Python/JS.
- **Fixtures:** correctness work that claims upstream interop must test against a
  file generated by Python `sleap-io` (extend `Tests/Fixtures/generate_fixtures.py`)
  or JS, not just a Swift self-round-trip.

## Milestone ladder

| Milestone | Theme | Epics | Why this order |
|---|---|---|---|
| **M1** | GUI editing core | E1 Labels API · E2 Instance/Frame · E3 Skeleton/Video accessors · E4 SwiftUI enablers | Every edit the GUI makes goes through these; mostly additive + cheap. |
| **M2** | Proofreading & merge | E5 Matching subsystem · E6 Merge/match cascade | Track/merge proofreading is the core annotation workflow after editing. |
| **M3** | SLP fidelity & modern formats | E7 Format ≥1.6 + datasets · E8 Provenance/identity round-trip · E9 Embed-on-save · E10 Sessions/cameras | We can't open files SLEAP writes today; correctness bugs live here. |
| **M4** | Video & relocation | E11 Video model + relocation · E12 Video backends/perf | Missing-video relocation blocks opening projects across machines/iPad. |
| **M5** | Rendering & overlays | E13 Rendering parity · E14 High-count perf (Metal) | Track-color + overlays + scale to 100+ instances (GUI Phase 4). |
| **M6** | Training backend | E15 numpy/tensor + splits · E16 Transforms | Enables `sleap.swift` backend; fixes TensorCodec correctness bugs. |
| **M7** | Format coverage & dispatch/CLI | E17 Interchange parity + new formats · E18 Dispatch/CLI/umbrella API | Interop with the wider SLEAP ecosystem + a clean public surface. |
| **M8** | Deferred / out of scope | E19 NWB/LEAP/remote tracking | Documented non-goals; keep visible, don't build now. |

## M1 — GUI editing core

### E1 — Labels editing & navigation API · `epic` `model` `gui-readiness`
The container the GUI drives. Sub-issues:

- **E1.1** O(1) frame & track index in `Labels` (`get_frame(video:frameIdx:)`,
  `reindex()`, invalidation on mutation). Fixes the known O(n) `frame(for:at:)`.
  *Tests:* lookup correctness vs linear scan on dense fixture; index rebuild after
  add/remove; multi-video isolation; lazy path uses `frameMetadata()` without
  materializing. *(M)*
- **E1.2** Rich subscripts + `find(video:frameIdx:returnNew:)` with `match_video`
  foreign-`Video` resolution (int / range / `[Int]` / `Video` / `(Video,Int)`).
  *Tests:* each overload; foreign-video object resolves to local by path/content. *(M)*
- **E1.3** `Labels.copy(openVideos:)` deep snapshot (identity-preserving clone).
  Unblocks safe save isolation + undo in the GUI. *Tests:* clone `!==` original but
  structurally equal; edits to clone don't touch original; identity tables deduped. *(L)*
- **E1.4** `Labels.clean(frames:instances:skeletons:tracks:videos:)` and
  `remove_predictions(clean:)`. *Tests:* removes empty frames but **preserves
  negative frames**; prunes unused skeletons/tracks/videos when asked. *(M)*
- **E1.5** Count accessors: `nUserInstances`, `nPredInstances`,
  `nFramesPerVideo`, `nInstancesPerTrack`, `userLabeledFrames`. *Tests:* vs known
  fixtures; O(1) on lazy where possible. *(S)*
- **E1.6** Annotation query families: `get_rois`/`get_masks`/`get_bboxes`/
  `get_centroids`/`get_label_images` (return what exists today; expand as E7 lands).
  *Tests:* per-frame and per-video gather. *(M)*

- **E2.4** `Instance.update_skeleton(namesOnly:)` /
  `replace_skeleton(_:nodeNamesMap:)` (+ predicted overrides). Resizes
  `PointsArray` to the new node set, preserving points by name. *Tests:* add/remove

- **E2.5** `LabeledFrame.remove_empty_instances()`, `remove_predictions()`,
  `unused_predictions`, `is_user_labeled`, `image`. *Tests:* drop all-invisible;

- **E2.6** `PointsArray.from_array` (D-column inference) / `from_dict(node→data)`.
  *Tests:* (N,2)/(N,3) inference; dict keyed by node name. *(S, backend)*

### E3 — Skeleton derived accessors & SLP codec fidelity · `epic` `model` `parity` `gui-readiness`
- **E3.1** Derived accessors: `nodeNames`, `edgeInds`, `edgeNames`,

### E4 — SwiftUI integration enablers · `epic` `gui-readiness`
Cross-cutting glue that makes the model GUI-friendly without forcing a particular UI.
- **E4.1** Coordinate-convention reference + doc: pixel-center, pre-1.1 0.5 shift,
  y-down image space vs CG/SwiftUI y-up, NaN-as-invisible. A `CoordinateConventions`
  doc-comment hub + helpers. *Tests:* round-trip helpers; document with examples. *(S, high leverage)*
- **E4.2** `SleapIO.version` constant + `provenance["sleap_io_swift_version"]`
  stamping on save + a "supported SLP versions / codecs" introspection. *Tests:*
  version present; stamp on save; introspection lists formats. *(S)*
- **E4.3** Error taxonomy: split `SleapIOError` into recoverable vs fatal, add
  `missingVideo`, `skeletonMismatch`, `mergeConflict`, and an `ErrorMode`
  (`strict`/`warn`/`continue`) parameter for load/merge. *Tests:* each mode's
  behavior on a bad frame. *(M)*
- **E4.4** Progress + cancellation contract: an `AsyncStream<Progress>` (or
  callback) threaded through `load`/`save`/`merge`/embed, with `Task` cancellation
  checks in the column reader + embed loop. *Tests:* progress monotonic; cancel
  stops work promptly. *(M)*
- **E4.5** Observable-friendliness: a documented change-notification story —
  `revision`/`objectWillChange`-style signal on mutation, stable `Identifiable`/
  `Hashable` on identity types, without breaking `@unchecked Sendable`. *Tests:*
  identity hashing stable across edits; notification fires on point edit / track
  change / add-remove. *(L)*
- **E4.6** Concurrency/snapshot contract doc: how to hand `Labels` to a background
  task safely (use `copy()` from E1.3); document isolation domains; audit
  `@unchecked Sendable` claims. *Tests:* concurrency stress test (extend
  `StressTests`). *(M)*
